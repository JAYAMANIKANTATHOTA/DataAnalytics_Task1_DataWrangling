# Data Dictionary

| Column Name           | Data Type | Description                        |
| --------------------- | --------- | ---------------------------------- |
| customer_id           | Integer   | Unique customer identifier         |
| customer_name         | String    | Customer name                      |
| dob                   | Date      | Date of birth                      |
| gender                | String    | Customer gender                    |
| city                  | String    | Customer city                      |
| order_date            | Date      | Date of purchase                   |
| product_category      | String    | Product category purchased         |
| revenue               | Float     | Revenue generated from purchase    |
| profit                | Float     | Profit generated from purchase     |
| website_visits        | Integer   | Number of website visits           |
| customer_age          | Integer   | Age derived from DOB               |
| profit_margin_percent | Float     | Profit as percentage of revenue    |
| revenue_category      | String    | Revenue category (Low/Medium/High) |
